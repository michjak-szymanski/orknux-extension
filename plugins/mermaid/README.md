# Mermaid

Renders Mermaid diagram text to SVG **offline, inside the sandbox** — the
renderer and its layout engine ship as the plugin's own libraries, so a
workflow can turn `graph TD` into a picture without a browser, a network, or
anything to install on the server.

Flowcharts, sequence diagrams and the rest of Mermaid's vocabulary, answered
as SVG text a downstream node can store, attach, or hand to the PDF plugin.
