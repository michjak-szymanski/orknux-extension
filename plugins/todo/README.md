# Todo

A todo list for the **agent's own plan** — not the user's. A model working a
long job holds its plan in its context, and a context is the one thing a long
job erodes; this is the list on paper. Five small verbs around one list kept
in the session store: break the request into tasks, work them one by one,
note what turns up, complete as you go, and check the remaining count before
calling anything finished.

The list lives exactly as long as the AI session and no other session ever
sees it. Needs no capability — nothing outside the session is reached.
